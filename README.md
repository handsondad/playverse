# Playverse 亲子小游戏

给孩子玩的网页小游戏合集，手机、平板、电脑点开就能玩，不用下载、不用注册，也没有广告。

👉 **在线游玩：<https://handsondad.github.io/playverse/>**

## 四大玩法分区

- **低龄陪玩**：小车拍一拍、动物叫叫乐、气球点点乐、颜色点点看、形状拍拍乐、数字点点乐、表情认一认 —— 大卡片、带语音，点错也没关系，适合低龄宝宝和大人一起点一点。
- **启蒙益智**：字母拼读启蒙、颜色形状分类、翻牌配对、泡泡连线救援、涂鸦互动动画、动物合唱团、星空观测员、水果计数乐、规律小火车、火眼找不同、迷你图形数独、趣味小天平 —— 在游戏里练习认字、数数、找规律、观察推理和涂鸦创作。
- **生活探索**：小小厨师配餐、小小邮差送信、果园分拣员、小小宠物诊所、迷你农场小镇、海底清洁队、森林巡护员、超市购物、滴答认时钟、天气穿搭屋 —— 走进日常作息、自理穿搭与自然场景，边玩边认识生活。
- **反应闯关**：算术闯关、迷宫解谜、节奏点点乐、亲子跑酷、打地鼠升级版、灯塔守护者、星星藏哪儿、桌上少了谁 —— 锻炼手眼协调、专注追踪、瞬时记忆与动脑闯关。

## 贴心特点

- **打开即玩，离线可用**：添加到手机主屏幕就能像 App 一样打开；玩过的游戏没有网络也能继续玩。
- **语音引导与护眼模式**：自带中文语音提示，底部可随时切换「标准 / 柔和 / 安静」模式，连续玩久了还会温柔提醒休息眼睛。
- **每日挑战**：许多游戏每天都有固定题目，适合一家人同场比一比。
- **安全纯粹**：无账号、无内购、不上传任何个人数据，游玩记录只保存在当前设备里。
