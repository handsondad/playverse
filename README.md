# Playverse 儿童小游戏

一组给孩子玩的网页小游戏，手机、平板、电脑的浏览器都能直接打开，不用下载、不用注册。
从需要大人陪着点一点的小宝宝，到上小学的孩子，都能找到适合的游戏。

**在线游玩：<https://handsondad.github.io/playverse/>**

## 怎么玩

1. 打开上面的网址，在首页选一个游戏。
2. 先选难度或主题，再点「开始」。
3. 每个游戏顶部都有一句玩法说明，语音也会提示下一步做什么。

想像 App 一样使用：在手机浏览器里选「添加到主屏幕」。联网玩过一次的游戏，之后没有网络也能打开。

## 给家长

- **护眼模式**：每个游戏底部都能在「标准 / 柔和 / 安静」之间切换。柔和模式语速放慢、音量降低；安静模式关掉音效，只播报必要的提示。在一个游戏里改了，其他游戏会跟着变。
- **语音引导**：可以开关，也可以选「关键」只播报重要提示，或「详细」多讲一些。
- **休息提醒**：部分游戏连续玩得比较久时，会提醒孩子休息一下、看看远处。
- **每日挑战**：很多游戏有「今日挑战」，同一天里每次打开都是同一关，适合和家人比一比。
- **数据统计**：底部能看到玩了几局、成绩和最好纪录。所有进度只保存在当前设备的浏览器里，不上传、不需要账号；清除浏览器数据会一起清掉。
- 所有操作都为手指点按设计；页面上的按钮也可以用键盘的 Tab 和回车操作。

## 在自己电脑上运行

需要在本地起一个小服务器再打开，直接双击网页文件是打不开游戏的：

- 用 VS Code 打开本项目，运行任务「启动本地小游戏服务器」，然后访问 <http://localhost:8123/>。
