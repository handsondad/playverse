# 小小宠物诊所开发记录

## 当前阶段

- 阶段：P2 完整版（特殊病例 + 主题天气）
- 页面：src/pet/index.html
- 核心逻辑：src/pet/petClinicGame.js

## 已实现能力

1. 三档难度：晨间接诊 / 午后门诊 / 夜间急诊。
2. 病例刷新：按 tick 节奏生成当前待接诊病例。
3. 分诊判定：点击同症状诊室判定成功，错误扣耐心。
4. 连对加分：连续正确分诊可获得额外分数。
5. 时间奖励：每完成 6 次正确分诊额外奖励 1 秒。
6. 队列预览：展示后续 5 个病例，辅助提前决策。
7. 通关规则：时间内达到目标接诊数量即可过关。
8. 今日门诊：按日期 + 难度固定种子序列。
9. 本地记录：最佳分持久化保存。
10. 结算面板：展示接诊数、分数、耐心、剩余时间。
11. 全局设置同步：语音引导、播报模式、护眼模式。
12. 特殊病例：加入急诊（超时惩罚）与 VIP（高奖励高风险）机制。
13. 主题诊所：支持暖心 / 花园 / 夜班三套主题切换。
14. 天气轮换：按周期切换天气并驱动场景背景变化。
15. 每日联动：主题参与今日门诊种子，形成稳定可复现挑战。
