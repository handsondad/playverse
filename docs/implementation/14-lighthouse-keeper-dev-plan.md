# 灯塔守护者开发记录

## 当前阶段

- 阶段：P2 天气干扰版
- 页面：src/lighthouse/index.html
- 核心逻辑：src/lighthouse/lighthouseGame.js

## 已实现能力

1. 三档难度：海湾巡逻 / 夜港守望 / 暴风灯塔。
2. 来船推进：按固定 tick 推进当前来船进港进度。
3. 灯光切换：点击信号灯按钮切换灯塔当前灯光。
4. 匹配判定：到港时灯光匹配即成功，否则损失生命。
5. 队列预览：展示后续来船信号，支持提前决策。
6. 计时与目标：时间结束前完成目标进港数即通关。
7. 每日航线：按日期与难度固定随机种子。
8. 本地记录：最佳分本地持久化。
9. 结算面板：展示进港、分数、生命、剩余时间。
10. 全局设置同步：语音引导、播报模式、护眼模式。
11. 港口天气事件：晴朗/迷雾/顺风/逆风循环变化并影响船速和识别难度。
12. 干扰船机制：显示信号可能为伪装，需根据节奏与判断切换灯光。
13. 双信号船机制：一艘船支持两种匹配灯光，提升策略空间。
