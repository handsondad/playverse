# 颜色形状分类开发记录

## 当前阶段

- 阶段：P2 可玩增强版
- 页面：src/sort/index.html
- 核心逻辑：src/sort/sortGame.js

## 已实现能力

1. 主玩法优先页面结构（模式/难度 -> 核心操作 -> 分类区 -> 底部辅助区）。
2. 三种模式：颜色分类 / 形状分类 / 混合分类。
3. 三档难度：慢慢分 / 刚刚好 / 小专家。
4. 点选物品 + 点选分类盒的触屏友好交互。
5. 倒计时、分数、正确/错误、剩余数量、历史最好分。
6. 每日挑战固定种子（当天同模式与同物品序列）。
7. 全局设置同步：语音、播报模式、护眼模式。
8. 本地统计：总局数、胜率、平均正确、平均错误、最佳连胜。
9. 支持拖拽吸附：物品可直接拖到分类盒。
10. 首次错误自动高亮正确分类盒，降低挫败感。
