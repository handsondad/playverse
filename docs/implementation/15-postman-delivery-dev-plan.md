# 小小邮差送信开发记录

## 当前阶段

- 阶段：P2 完整版（特殊信件 + 主题天气）
- 页面：src/postman/index.html
- 核心逻辑：src/postman/postmanGame.js

## 已实现能力

1. 三档难度：社区慢送 / 街区速递 / 城市急送。
2. 信件刷新：按 tick 节奏生成当前待投递信件。
3. 投递判定：点击同色信箱判定成功，错误扣生命。
4. 连对加分：连续正确投递可获得额外分数。
5. 队列预览：展示后续 5 封信件，辅助提前决策。
6. 通关规则：时间内达到目标投递数即可过关。
7. 今日路线：按日期 + 难度固定种子序列。
8. 本地记录：最佳分持久化保存。
9. 结算面板：展示投递数、分数、生命、剩余时间。
10. 全局设置同步：语音引导、播报模式、护眼模式。
11. 特殊信件：加入加急件（超时惩罚）与挂号件（高奖励高风险）机制。
12. 特殊反馈：当前信件与队列显示特殊标签，便于提前决策。
13. 主题包：支持经典/校园/节日三套邮局主题切换。
14. 天气轮换：按周期切换天气并驱动场景背景变化。
15. 主题联动：主题会参与每日路线种子，形成稳定可复现挑战。
