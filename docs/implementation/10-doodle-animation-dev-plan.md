# 涂鸦互动动画开发记录

## 当前阶段

- 阶段：P2 导出版（作品库 + 图卡 + 短动图）
- 页面：src/doodle/index.html
- 核心逻辑：src/doodle/doodleGame.js

## 已实现能力

1. 触屏绘制：支持画笔、橡皮、撤销、清空、颜色盘与粗细调节。
2. 动作模板：跳跃、摆手、旋转三种模板可切换。
3. 实时播放：绘制完成后可一键播放动画并即时预览。
4. 动画循环：模板支持循环时长与参数配置。
5. 录音能力：支持 3-10 秒配音录制、试听与清除。
6. 同步播放：点击播放动画时自动触发配音同步。
7. 本地作品库：支持保存作品缩略图、模板配置与笔画数据。
8. 作品重开：可从作品库载入继续编辑，也可删除历史作品。
9. 导出图卡：可一键导出 PNG 分享图卡（含模板、笔画、配音状态信息）。
10. 短动图导出：支持导出 WebM 短动画片段，便于家长分享。
11. 全局设置同步：语音引导、播报模式、护眼模式。
