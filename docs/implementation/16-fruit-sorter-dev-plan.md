# 果园分拣员开发记录

## 当前阶段

- 阶段：P2 完整版（特殊水果 + 主题天气）
- 页面：src/fruit/index.html
- 核心逻辑：src/fruit/fruitGame.js

## 已实现能力

1. 三档难度：晨间采摘 / 午后分拣 / 傍晚冲刺。
2. 水果刷新：按 tick 节奏生成当前待分拣水果。
3. 分拣判定：点击同色果篮判定成功，错误扣生命。
4. 连对加分：连续正确分拣可获得额外分数。
5. 时间奖励：每完成 6 次正确分拣额外奖励 1 秒。
6. 队列预览：展示后续 5 颗水果，辅助提前决策。
7. 通关规则：时间内达到目标分拣数量即可过关。
8. 今日果园：按日期 + 难度固定种子序列。
9. 本地记录：最佳分持久化保存。
10. 结算面板：展示分拣数、分数、生命、剩余时间。
11. 全局设置同步：语音引导、播报模式、护眼模式。
12. 特殊水果：加入易坏果（超时扣生命）与双倍果（高奖励高风险）机制。
13. 主题果园：支持晨曦 / 山谷 / 丰收三套主题切换。
14. 天气轮换：按周期切换天气并驱动场景背景变化。
15. 每日联动：主题参与今日果园种子，形成稳定可复现挑战。
