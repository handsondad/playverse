# 算术闯关开发记录

## 当前阶段

- 阶段：P2 复习版
- 页面：src/math/index.html
- 核心逻辑：src/math/mathGame.js

## 已实现能力

1. 三个章节：加法新手、加减闯关、乘法挑战。
2. 战斗闭环：出题 -> 选答案 -> 攻击怪物 / 玩家受伤 -> 结算。
3. 连击技能：达到阈值时自动追加伤害。
4. 每日挑战：按日期固定章节与种子。
5. 全局设置同步：语音引导、播报模式、护眼模式。
6. 结果页：显示分数、正确数、错误数、准确率、最佳连击。
7. 错题记录：答错题目会写入本地错题本，最多保留最近 20 道。
8. 复习关：可从错题本抽取最近错题进入复习模式，通关后自动移除。
