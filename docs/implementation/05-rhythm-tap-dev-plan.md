# 节奏点点乐开发记录

## 当前阶段

- 阶段：P2 可玩增强版
- 页面：src/rhythm/index.html
- 核心逻辑：src/rhythm/rhythmGame.js

## 已实现能力

1. 主玩法优先页面结构（歌曲/难度 -> 核心操作 -> 轨道演奏区 -> 底部辅助区）。
2. 两首儿童友好节奏曲：小太阳节拍 / 彩虹蹦蹦拍。
3. 三档难度：慢慢拍 / 刚刚好 / 节奏王。
4. 四轨点击判定：Perfect / Good / Miss。
5. 连击、分数、进度条、最好分、结算命中率。
6. 支持触屏点按和键盘 `A S D F / 方向键`。
7. 每日挑战固定歌曲与难度。
8. 全局设置同步：语音、播报模式、护眼模式。
9. 本地统计：总局数、胜率、平均分、平均命中率、最佳连击。
10. 新增长按音符，支持按下并保持到尾巴结束。
11. 演奏区增加拍点脉冲提示，帮助低龄玩家跟节奏。
12. 手感微调：增加输入时间偏移、晚点容差、长按抬手缓冲，触屏更稳。
13. 根据护眼模式切换判定宽容度（标准/柔和/安静三档）。
14. 新增简易延迟校准：跟拍 4 次自动估算偏移并持久化到本地。
