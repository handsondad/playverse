# 迷你农场小镇开发记录

## 当前阶段

- 阶段：P2 可玩增强版
- 页面：src/farm/index.html
- 核心逻辑：src/farm/farmGame.js

## 已实现能力

1. 主循环闭环：选种子 -> 种植 -> 等待成熟 -> 收获 -> 交付订单。
2. 三种作物基础差异：成熟时间、产量、售价、经验收益。
3. 订单系统：随机作物与数量、交付奖励金币与经验。
4. 经营成长：等级提升后提高后续订单奖励。
5. 每日挑战：固定日种子，订单数量略增。
6. 触屏优先操作：地块点按种植与收获，按钮软点击反馈。
7. 引导与反馈：顶部引导文案、结果提示、成熟地块高亮。
8. 全局设置同步：语音引导、播报模式、护眼模式。
9. 本地统计：总天数、总收获、完成订单、最高等级、累计金币。
10. 天气系统：每日随机天气影响成长速度、产量与经验收益。
11. 土地肥力：每块地独立肥力，影响成熟速度与收获收益。
12. 施肥功能：消耗金币恢复低肥力地块，形成轻策略循环。
13. 加工台玩法：消耗仓库作物制作沙拉/果汁，换取额外金币与经验。
14. 新手引导条：按当前状态高亮下一步操作（开始/种植/收获/交付/加工）。
15. 轻任务系统：连续收获或指定作物交付任务，自动结算奖励并刷新新任务。
