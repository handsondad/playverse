# 森林巡护员开发记录

## 当前阶段

- 阶段：P2 增强版
- 页面：src/forest/index.html
- 核心逻辑：src/forest/forestGame.js

## 已实现能力

1. 三档难度：清晨巡林 / 午后巡线 / 暮色守望。
2. 线索刷新：按 tick 节奏生成当前待登记线索。
3. 登记判定：点击同类型观察站判定成功，错误扣体力。
4. 连对加分：连续正确登记可获得额外分数。
5. 时间奖励：每完成 6 次正确登记额外奖励 1 秒。
6. 队列预览：展示后续 5 条线索，辅助提前决策。
7. 通关规则：时间内达到目标识别数量即可过关。
8. 今日林线：按日期 + 难度固定种子序列。
9. 本地记录：最佳分持久化保存。
10. 结算面板：展示识别数、分数、体力、剩余时间。
11. 全局设置同步：语音引导、播报模式、护眼模式。
12. 特殊线索：紧急线索限时处理，稀有线索双倍分与高惩罚。
13. 主题林区：松林/竹林/枫林三套主题一键切换。
14. 天气轮换：按关卡周期在主题天气池中切换。
15. 线索标记：当前线索与后续队列展示普通/紧急/稀有类型。
