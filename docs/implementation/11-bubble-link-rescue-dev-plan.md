# 泡泡连线救援开发记录

## 当前阶段

- 阶段：P2 特殊泡泡版
- 页面：src/bubble/index.html
- 核心逻辑：src/bubble/bubbleGame.js

## 已实现能力

1. 触屏连线：按住并划过相邻同色泡泡，松手消除。
2. 三档难度：慢慢连 / 刚刚好 / 挑战王。
3. 棋盘规则：至少连 2 个同色才生效，支持拖动回退一步。
4. 消除反馈：消除后触发下落补位，并按长度与连击结算分数。
5. 胜负条件：在倒计时结束前达到目标分数即可通关。
6. 提示系统：可高亮一组可连泡泡，降低卡关挫败。
7. 每日挑战：按日期固定种子，生成当日固定棋盘序列。
8. 本地记录：历史最好分、总局数、胜场、总分、最高连击。
9. 全局设置同步：语音引导、播报模式、护眼模式。
10. 特殊泡泡：支持炸弹、彩虹、冻结三种特殊效果，提升节奏变化。
11. 动画反馈：支持连线轨迹与消除结算飘字，连线手感更清晰。
