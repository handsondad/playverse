# 翻牌配对开发执行计划（第一阶段）

## 目标

在当前工作区完成一个可运行、可扩展的翻牌配对 MVP，并形成后续迭代任务清单。

## 任务拆解与优先级

### P0（已完成）

1. 页面骨架与基础 UI
2. 关卡配置文件设计
3. 核心状态机（翻牌、判定、回翻、通关）
4. 倒计时与分数逻辑
5. 本地最佳成绩存储
6. 结算流程

### P1（已完成）

1. 星级结算规则（时间/失误/步数）
2. 道具系统（提示、保险）
3. 新手引导（首关高亮提示）
4. 音效系统（命中、失败、通关）

### P2（已完成）

1. 每日挑战（固定随机种子）
2. 成长系统（星星解锁主题）
3. UI 动画增强（连击、撒花）
4. 数据统计面板（平均用时、胜率）

已实现项：每日挑战、章节解锁、数据统计面板、星级解锁主题、连击与庆祝动画、每日本地榜。
未实现项：主题成长奖励细化（贴纸/皮肤）、云端排行榜。

## 代码约定

1. 核心逻辑与渲染分离。
2. 所有关卡和主题内容走配置，不写死在逻辑层。
3. 状态更新必须通过统一 `emit` 输出。

## 测试清单

1. 连续快速点击不应导致卡牌错乱。
2. 倒计时归零后不可继续翻牌。
3. 完成最后一对后必须立即结算。
4. 切换主题后最佳成绩按主题独立统计。
5. 移动端横竖屏下布局不溢出。

## 工时预估（后续）

1. P1 合计：2-3 天
2. P2 合计：3-5 天
