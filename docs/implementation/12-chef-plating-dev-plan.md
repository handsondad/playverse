# 小小厨师配餐开发记录

## 当前阶段

- 阶段：P2 交互增强版
- 页面：src/chef/index.html
- 核心逻辑：src/chef/chefGame.js

## 已实现能力

1. 三档难度：慢慢配 / 刚刚好 / 忙碌厨房。
2. 订单系统：随机抽取当前菜谱并显示所需食材与奖励。
3. 配餐流程：点选食材放入餐盘，支持撤回单格与清空餐盘。
4. 提交流程：按食材种类与数量判定，不依赖摆放顺序。
5. 错误反馈：会指出缺少或多放的食材，便于孩子修正。
6. 胜负规则：在倒计时结束前完成目标订单数即可通关。
7. 每日挑战：按日期固定菜单序列。
8. 本地记录：历史最好分、总局数、完成订单数、最佳连击。
9. 全局设置同步：语音引导、播报模式、护眼模式。
10. 拖拽摆盘：支持食材拖拽到指定餐盘格，也可拖拽调整格位顺序。
11. 顾客反馈：根据配餐结果显示等待/满意/超满意/失望表情状态。
12. 主题菜单包：支持早餐厨房 / 野餐时光 / 节日派对三套主题菜单。
