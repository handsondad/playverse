# 迷宫解谜开发记录

## 当前阶段

- 阶段：P2 机关版
- 页面：src/maze/index.html
- 核心逻辑：src/maze/mazeGame.js

## 已实现能力

1. 三个预制迷宫关卡，支持选关与今日迷宫。
2. 键盘和触屏双输入移动，角色可在方格中稳定移动。
3. 基础机关闭环：墙体阻挡、钥匙收集、门锁开启、陷阱提示、出口通关。
4. P2 机关扩展：地板开关开启闸门、一次性桥、双向传送点。
5. 提示按钮：卡住时可获得下一步方向建议。
6. 过程统计：步数、时间、钥匙数量、陷阱次数、机关开启、桥面坍塌。
7. 结果结算：按目标步数与建议时间给出 1-3 星评价。
8. 全局设置同步：语音引导、播报模式、护眼模式。
