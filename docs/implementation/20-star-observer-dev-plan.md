# 星空观测员开发记录

## 当前阶段

- 阶段：P2 增强版
- 页面：src/star/index.html
- 核心逻辑：src/star/starGame.js

## 已实现能力

1. 三档难度：黄昏观星 / 夜空记录 / 银河巡测。
2. 线索刷新：按 tick 节奏生成当前待记录星图。
3. 记录判定：点击同类型观测台判定成功，错误扣精力。
4. 连对加分：连续正确记录可获得额外分数。
5. 时间奖励：每完成 6 次正确记录额外奖励 1 秒。
6. 队列预览：展示后续 5 条星图，辅助提前决策。
7. 通关规则：时间内达到目标记录数量即可过关。
8. 今日星图：按日期 + 难度固定种子序列。
9. 本地记录：最佳分持久化保存。
10. 结算面板：展示记录数、分数、精力、剩余时间。
11. 全局设置同步：语音引导、播报模式、护眼模式。
12. 特殊天象：限时信号超时惩罚，稀有天象双倍分与高惩罚。
13. 主题星域：深空/海湾/星云三套主题一键切换。
14. 天空轮换：按关卡周期在主题天空池中切换。
15. 信号标记：当前信号与后续队列展示普通/限时/稀有类型。
