# 字母拼读启蒙开发记录

## 当前阶段

- 阶段：P2 可玩增强版
- 页面：src/spell/index.html
- 核心逻辑：src/spell/spellGame.js

## 已实现能力

1. 主题选择：动物、食物两个基础词包。
2. 题目流程：图片提示 + 单词拼读 + 自动判定。
3. 字母池玩法：点字母入槽，点槽位可撤回。
4. 提示机制：每局 2 次提示，自动补对单个槽位。
5. 练习闭环：完成全部题目后显示结果与准确率。
6. 每日练习：按日期固定主题与种子。
7. 全局设置同步：语音引导、播报模式、护眼模式。
8. 发音队列：可听整词，答对后自动按音节/拼音再播报完整词。
9. 拼音模式：新增声母/韵母拼读题，可与字母主题并列练习。
