# 海底清洁队开发记录

## 当前阶段

- 阶段：P2 完整版（特殊漂浮物 + 主题海域）
- 页面：src/ocean/index.html
- 核心逻辑：src/ocean/oceanGame.js

## 已实现能力

1. 三档难度：海湾巡查 / 礁区守护 / 深海突击。
2. 漂浮物刷新：按 tick 节奏生成当前待清理漂浮物。
3. 分类判定：点击同类型回收网判定成功，错误扣生命。
4. 连对加分：连续正确清理可获得额外分数。
5. 时间奖励：每完成 6 次正确清理额外奖励 1 秒。
6. 队列预览：展示后续 5 个漂浮物，辅助提前决策。
7. 通关规则：时间内达到目标清理数量即可过关。
8. 今日海域：按日期 + 难度固定种子序列。
9. 本地记录：最佳分持久化保存。
10. 结算面板：展示清理数、分数、生命、剩余时间。
11. 全局设置同步：语音引导、播报模式、护眼模式。
12. 特殊漂浮物：加入危险品（超时扩散）与宝藏件（高奖励高风险）机制。
13. 主题海域：支持晴蓝海湾 / 珊瑚礁区 / 夜潮海域三套主题切换。
14. 天气轮换：按周期切换海况并驱动场景背景变化。
15. 每日联动：主题参与今日海域种子，形成稳定可复现挑战。
