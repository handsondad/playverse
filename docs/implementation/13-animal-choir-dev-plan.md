# 动物合唱团开发记录

## 当前阶段

- 阶段：P2 模仿奖励版
- 页面：src/choir/index.html
- 核心逻辑：src/choir/choirGame.js

## 已实现能力

1. 三档难度：慢慢唱 / 刚刚好 / 合唱大师。
2. 听后复现：先播放系统序列，再进入玩家输入阶段。
3. 轮次成长：每轮自动追加一个动物音符。
4. 时间机制：倒计时结束即结算。
5. 容错机制：输错重置当前轮输入并扣除 3 秒。
6. 提示机制：可提示当前下一步动物，扣除 2 秒。
7. 每日挑战：按日期 + 难度生成固定种子序列。
8. 本地记录：最好连对持久化存储。
9. 结算面板：展示胜负、轮次、提示次数、剩余时间。
10. 全局设置同步：语音引导、播报模式、护眼模式。
11. 主题音色包：森林/海洋/农场三套音色可切换，含不同波形、音高偏移与节奏速度。
12. 模仿模式轨迹：展示当前轮序列轨迹，支持播放阶段与输入阶段进度可视化。
13. 连续完美奖励：无失误且无提示完成回合可获得时间奖励，并记录最佳完美连击。
