# 16 果园分拣员（Fruit Sorter）

## 1. 项目定位

- 类型：颜色匹配 / 反应训练
- 目标年龄：4-9 岁
- 单局时长：3-5 分钟
- 核心体验：识别水果颜色并快速放入同色果篮

## 2. 核心玩法

1. 系统持续生成待分拣水果。
2. 每个水果对应一个目标颜色果篮。
3. 玩家点击同色果篮完成分拣。
4. 分拣正确加分并增加连对，分拣错误扣生命。
5. 在时间结束前达到目标分拣数量即可通关。

## 3. 主要系统

### 3.1 难度系统

- 三档难度：晨间采摘 / 午后分拣 / 傍晚冲刺。
- 难度通过刷新间隔、目标数量、可用颜色和生命值体现。

### 3.2 队列预览系统

- 当前水果显示目标果篮。
- 后续队列展示 5 颗水果，支持提前规划。
- 今日果园通过日期种子固定，便于重复挑战。

### 3.3 特殊水果与主题系统

- 易坏果需要优先分拣，放置过久会损失生命。
- 双倍果分拣正确时分数翻倍，分错惩罚更重。
- 提供晨曦果园 / 山谷果园 / 丰收果园三套主题包。
- 每局按周期轮换天气，并同步切换背景氛围。

### 3.4 评分与反馈

- 分拣成功按连对获得额外分数。
- 每完成 6 次正确分拣奖励 1 秒。
- 分拣失败给出明确提示并扣减生命。
- 结算展示分拣数、分数、生命和剩余时间。

### 3.5 辅助与设置

- 全局语音、播报、护眼模式同步可用。
- 安静模式关闭提示音，减少听觉刺激。

## 4. 页面流程

1. 选择难度。
2. 开始分拣或今日果园。
3. 观察当前水果并点击目标果篮。
4. 持续分拣直至通关或失败。
5. 查看结算并可快速重开。

## 6. 美术与音频

- 果园暖色系配色，果篮按钮使用高对比色块。
- 水果与果篮使用 emoji，提升低龄识别效率。
- 不同果篮按钮对应不同音高提示。

## 7. 技术实现要点

- 统一 100ms tick 管理时间与水果刷新。
- 队列固定长度，保证节奏稳定。
- 随机数支持种子，确保每日路线可复现。

## 8. 里程碑

1. MVP（2 天）：分拣判定、计时、结算。
2. 增强（2 天）：每日果园、本地最佳分、连对加分。
3. 打磨（2 天）：语音引导与护眼模式联动。
4. 扩展（2 天）：主题果园、特殊水果与天气轮换。

## 9. 验收标准

1. 触屏操作可以稳定分拣一整局。
2. 分拣错误反馈明确且可恢复。
3. 结算数据与过程一致。

## 10. 风险与规避

- 风险：颜色过多导致识别压力增大。
- 规避：低难度限制颜色数量并放慢刷新速度。
