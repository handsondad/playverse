# 11 泡泡连线救援（Bubble Link Rescue）

## 1. 项目定位

- 类型：益智连线
- 目标年龄：5-12 岁
- 单局时长：3-8 分钟
- 核心体验：顺手连、立刻消、连续触发小惊喜

## 2. 核心玩法

1. 孩子按住一个泡泡开始连线。
2. 划过相邻的同色泡泡即可延长路径。
3. 松手后整条路径消除，棋盘自动下落补位。
4. 在倒计时结束前达到目标分数即可完成救援。

## 3. 主要系统

### 3.1 连线消除系统

- 仅允许上下左右相邻连线。
- 至少连 2 个泡泡才会生效。
- 支持滑回上一步撤销路径，降低误触成本。

### 3.2 特殊泡泡系统

- 炸弹泡泡：消除时会炸开周围一圈。
- 彩虹泡泡：可与任意颜色连线，并能清掉该颜色的更多泡泡。
- 冻结泡泡：消除后奖励额外时间，适合低龄玩家翻盘。

### 3.3 提示与每日挑战

- 提示按钮高亮一组可连泡泡。
- 每日挑战按日期固定随机种子，保证当天体验一致。

### 3.4 成绩与成长

- 记录历史最好分、最高连击。
- 累积总局数、胜场与总分，便于后续扩展章节成长。

## 4. 页面流程

1. 选难度：慢慢连 / 刚刚好 / 挑战王。
2. 开始游戏：进入棋盘并开始倒计时。
3. 连线消除：获得分数、触发特殊泡泡效果。
4. 结算：显示得分、目标、最高连击和消除数量。

## 6. 美术与音频

- 气泡色彩要明快、圆润，强调轻松感。
- 被选中的路径要有明显高亮反馈。
- 特殊泡泡用简单图标区分，保证低龄玩家一眼识别。

## 7. 技术实现要点

- 连线路径必须严格校验相邻关系与颜色匹配规则。
- 特殊泡泡效果要与基础消除流程解耦，避免状态错乱。
- 棋盘重排后必须保证仍存在至少一组可连泡泡。

## 8. 里程碑

1. MVP（3 天）：基础连线、计时、结算。
2. 增强（3 天）：特殊泡泡、每日挑战、统计记录。
3. 打磨（2 天）：轨迹动画、章节关卡、主题皮肤。

## 9. 验收标准

1. 连线操作在触屏设备上稳定，不出现跳格误连。
2. 特殊泡泡效果能稳定触发且不破坏棋盘补位。
3. 每局结束后分数、连击和最好成绩正确记录。

## 10. 风险与规避

- 风险：特殊泡泡叠加时导致清除逻辑混乱。
- 规避：统一先收集要清除的格子，再一次性结算与补位。
