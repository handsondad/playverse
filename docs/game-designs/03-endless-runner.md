# 03 横版跑酷收集（Endless Runner）

## 1. 项目定位

- 类型：动作反应
- 目标年龄：6-12 岁
- 单局时长：2-5 分钟
- 核心体验：速度感、躲避与收集并行

## 2. 核心玩法

1. 角色自动前进。
2. 玩家点击或按键触发跳跃（可二段跳）。
3. 躲避障碍并收集金币。
4. 撞击障碍后结束或扣血。

## 3. 主要系统

### 3.1 运动系统

- 地面速度随时间提升。
- 跳跃曲线可配置（初速度、重力）。

### 3.2 生成系统

- 障碍、金币按波次生成。
- 保证可通性：最小反应时间校验。

### 3.3 角色成长

- 金币解锁角色皮肤与尾迹。
- 每日任务奖励强化道具。

### 3.4 道具系统

- 护盾：抵挡一次碰撞。
- 磁铁：自动吸附金币。
- 慢速：短时降低地图速度。

## 4. 页面流程

1. 首页：开始、角色、任务。
2. 游戏页：距离、金币、血量、道具。
3. 结算页：本局成绩、任务进度、奖励。

## 5. 配置结构（示例）

```json
{
  "stageId": "R1",
  "baseSpeed": 240,
  "speedRampPerSec": 1.6,
  "obstaclePatterns": ["single", "double-gap", "high-low"],
  "coinRate": 0.6
}
```

## 6. 美术与音频

- 场景分层卷动（前景/中景/背景）。
- 跳跃、落地、碰撞、拾取音效分离。
- 速度提升时增加风声或屏幕速度线。

## 7. 技术实现要点

- 采用对象池管理障碍与金币。
- 物理检测优先 AABB，再做精细判定。
- 生成器内置可通关规则，避免不可躲组合。

## 8. 里程碑

1. MVP（4 天）：移动、跳跃、障碍、结算。
2. 增强（3 天）：道具、任务、皮肤。
3. 打磨（2 天）：动画分层、性能优化。

## 9. 验收标准

1. 不出现“必死障碍组合”。
2. 输入延迟低于 100ms 体感。
3. 低端设备长时间运行不掉帧严重。

## 10. 风险与规避

- 风险：玩法单一。
- 规避：加入阶段事件和随机地形变化。
