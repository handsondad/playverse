# 14 灯塔守护者（Lighthouse Keeper）

## 1. 项目定位

- 类型：反应决策 / 视觉匹配
- 目标年龄：5-10 岁
- 单局时长：3-6 分钟
- 核心体验：快速识别来船信号，切换正确灯光护航进港

## 2. 核心玩法

1. 雷达持续出现来船，每艘船有一个信号标记。
2. 玩家在船抵港前切换灯塔到相同信号。
3. 匹配成功获得分数并提升连护。
4. 匹配失败会损失生命值。
5. 在时间结束前完成目标进港数量即可通关。

## 3. 主要系统

### 3.1 难度系统

- 三档难度：海湾巡逻 / 夜港守望 / 暴风灯塔。
- 难度通过船速、刷新间隔、目标船数和生命值差异体现。

### 3.2 航线系统

- 实时显示当前来船和后续队列。
- 每日航线按日期种子固定，方便重复挑战。

### 3.3 天气与干扰系统

- 天气事件在局内循环切换：晴朗/迷雾/顺风/逆风。
- 顺风与逆风会直接影响船只推进速度。
- 迷雾会降低信号可见度，增加判断难度。
- 干扰船会展示伪装信号，双信号船支持两种匹配方式。

### 3.4 评分与反馈

- 成功护航有基础分与连护加成。
- 失败立即给出偏航反馈并扣生命。
- 结算展示进港数、分数、剩余生命和剩余时间。

### 3.5 辅助与设置

- 支持语音引导、播报模式、护眼模式。
- 护眼模式影响音频强度，安静模式关闭音效。

## 4. 页面流程

1. 选择难度。
2. 开始守护（或今日航线）。
3. 观察当前来船信号并切换灯光。
4. 连续护航直到完成目标或失败。
5. 查看结算并可快速重开。

## 6. 美术与音频

- 海港雷达风格，主色偏海蓝。
- 信号按钮采用高对比色块 + emoji，降低识别门槛。
- 不同信号对应不同音高，建立快速联想。

## 7. 技术实现要点

- 游戏主循环统一 100ms tick，便于跨设备稳定。
- 来船对象包含信号、进度与队列位置。
- 种子随机用于每日航线复现。

## 8. 里程碑

1. MVP（2 天）：来船推进、灯光切换、胜负结算。
2. 增强（2 天）：每日航线、本地最佳分、连护加分。
3. 打磨（2 天）：港口天气事件、干扰船/双信号船、节奏反馈。
4. 扩展（2 天）：信号主题包与章节任务。

## 9. 验收标准

1. 触屏操作下可稳定切换灯光并完成一局。
2. 失败反馈清晰，不会出现无响应状态。
3. 结算数据与过程表现一致。

## 10. 风险与规避

- 风险：高难度节奏过快导致挫败。
- 规避：低难度限制信号种类，逐步引入高复杂度信号。
