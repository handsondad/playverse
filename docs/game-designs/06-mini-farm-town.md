# 06 迷你农场/小镇（Mini Farm Town）

## 1. 项目定位

- 类型：轻建造经营
- 目标年龄：6-12 岁
- 单局时长：5-15 分钟
- 核心体验：种植收获、布置创造、长期成长

## 2. 核心玩法

1. 玩家种植作物并等待成熟。
2. 收获资源用于建造和装饰。
3. 完成订单获得金币与经验。
4. 升级解锁新建筑与新地块。

## 3. 主要系统

### 3.1 生产系统

- 作物有生长时长、产量、售价。
- 加速道具可缩短成熟时间。

### 3.2 建造系统

- 地块网格化摆放建筑和装饰。
- 建筑提供功能加成（仓库上限、订单奖励）。

### 3.3 任务系统

- 主线任务：引导基础循环。
- 日常任务：提升留存和目标感。

### 3.4 经济系统

- 软货币：金币。
- 成长货币：经验和星星。
- 平衡原则：避免过度等待造成流失。

## 4. 页面流程

1. 主城页：地块操作、菜单入口。
2. 商店页：建筑/装饰购买。
3. 订单页：任务交付与奖励。
4. 仓库页：资源管理。

## 5. 配置结构（示例）

```json
{
  "cropId": "carrot",
  "growTimeSec": 120,
  "yield": 2,
  "sellPrice": 8,
  "xp": 3
}
```

## 6. 美术与音频

- 俯视角卡通风格，块面清晰。
- 成熟状态需强辨识度。
- 场景环境音（鸟鸣、风声）增强陪伴感。

## 7. 技术实现要点

- 离线收益：记录时间戳，回到游戏后结算。
- 网格占用检测与可视化高亮。
- 存档结构版本化，便于后续更新兼容。

## 8. 里程碑

1. MVP（6 天）：种植、收获、订单、存档。
2. 增强（4 天）：建筑摆放、升级解锁。
3. 打磨（3 天）：离线收益、主题节日活动。

## 9. 验收标准

1. 24 小时离线后回档结算正确。
2. 经济曲线平稳，不出现卡关。
3. 新手 10 分钟内完成首次闭环。

## 10. 风险与规避

- 风险：开发体量偏大。
- 规避：先做农场核心，再逐步拓展小镇系统。
