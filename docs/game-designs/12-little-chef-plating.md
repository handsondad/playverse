# 12 小小厨师配餐（Little Chef Plating）

## 1. 项目定位

- 类型：认知配餐 / 轻经营
- 目标年龄：4-10 岁
- 单局时长：3-7 分钟
- 核心体验：看订单、选食材、完成摆盘

## 2. 核心玩法

1. 屏幕给出一张顾客订单卡。
2. 孩子从食材区点选需要的食材放进餐盘。
3. 放满后点击提交，系统判定是否与订单一致。
4. 在时间结束前完成足够多的订单即可过关。

## 3. 主要系统

### 3.1 订单系统

- 订单包含菜名、所需食材和奖励分。
- 难度越高，订单数量越多、食材组合越复杂。

### 3.2 配餐系统

- 食材以大卡片形式展示，支持触屏点选。
- 已放入餐盘的食材可一键撤回或整盘清空。
- 提交时按顺序无关、数量精确进行判定。

### 3.3 反馈系统

- 正确配餐显示顾客满意反馈。
- 错误时指出缺少或多放的食材，降低挫败感。
- 连续成功会形成小连击奖励。

### 3.4 每日挑战与统计

- 每日挑战按日期固定订单序列。
- 记录总局数、完成订单数、平均正确率和最佳连击。

## 4. 页面流程

1. 选难度。
2. 开始营业。
3. 查看订单并选食材。
4. 提交餐盘。
5. 结算分数与完成订单数。

## 5. 配置结构（示例）

```json
{
  "id": "normal",
  "name": "刚刚好",
  "timeLimitSec": 90,
  "targetOrders": 5,
  "menuPool": ["fruit-bowl", "veggie-plate", "happy-breakfast"]
}
```

## 6. 美术与音频

- 食材卡片要大、颜色鲜明、名称清晰。
- 餐盘区域像儿童餐盘，摆放反馈明显。
- 音效偏轻快，提交成功有小铃声。

## 7. 技术实现要点

- 订单和菜谱全部配置化，便于后续加主题菜单。
- 配餐判定采用“食材集合 + 数量”比较，不依赖顺序。
- 需要良好的触屏点击反馈，避免连续误点。

## 8. 里程碑

1. MVP（3 天）：订单、选食材、提交结算。
2. 增强（3 天）：每日挑战、统计、连击反馈。
3. 打磨（2 天）：拖拽摆盘、主题菜单、奖励贴纸。

## 9. 验收标准

1. 孩子能在不看说明的情况下完成一单。
2. 提交后缺少/多余食材提示明确。
3. 每局结束后分数、订单数和连击正确记录。

## 10. 风险与规避

- 风险：食材种类多时界面拥挤。
- 规避：P1 控制在 6-8 种食材，使用大按钮分组展示。
