# 19 森林巡护员（Forest Ranger）

## 1. 项目定位

- 类型：类型匹配 / 反应训练
- 目标年龄：4-9 岁
- 单局时长：3-5 分钟
- 核心体验：识别森林线索并快速送到对应观察站

## 2. 核心玩法

1. 系统持续生成待登记线索。
2. 每条线索对应一个目标观察站。
3. 玩家点击同类型观察站完成登记。
4. 登记正确加分并增加连对，登记错误扣体力。
5. 在时间结束前达到目标识别数量即可通关。

## 3. 主要系统

### 3.1 难度系统

- 三档难度：清晨巡林 / 午后巡线 / 暮色守望。
- 难度通过刷新间隔、目标数量、可用观察站和体力值体现。

### 3.2 队列预览系统

- 当前线索显示目标观察站。
- 后续队列展示 5 条线索，支持提前规划。
- 今日林线通过日期种子固定，便于重复挑战。

### 3.3 评分与反馈

- 登记成功按连对获得额外分数。
- 每完成 6 次正确登记奖励 1 秒。
- 登记失败给出明确提示并扣减体力。
- 结算展示识别数、分数、体力和剩余时间。

### 3.4 特殊线索系统（P2）

- 紧急线索：出现后需在限时内完成，超时会扣体力。
- 稀有线索：识别正确双倍分，识别错误额外扣体力。
- 队列预览会标记紧急/稀有，方便提前决策。

### 3.5 主题林区与天气系统（P2）

- 提供松林巡线、竹林晨露、枫林暮巡三套主题。
- 每个主题绑定独立天气池，局内按周期切换天气。
- 天气变化同步在界面与提示文案中展示，增强节奏感。

### 3.6 辅助与设置

- 全局语音、播报、护眼模式同步可用。
- 安静模式关闭提示音，减少听觉刺激。

## 4. 页面流程

1. 选择难度。
2. 开始巡护或今日林线。
3. 选择主题林区并确认当日天气序列。
4. 观察当前线索并点击目标观察站。
5. 紧急线索优先处理，稀有线索争取高分。
6. 持续登记直至通关或失败。
7. 查看结算并可快速重开。

```json
  "stationIds": ["track", "leaf", "sound", "nest"]

```

## 6. 美术与音频

- 森林自然配色，观察站按钮使用高对比色块。
- 线索与观察站使用 emoji，提升低龄识别效率。
- 不同观察站按钮对应不同音高提示。

## 7. 技术实现要点

- 统一 100ms tick 管理时间与线索刷新。
- 队列固定长度，保证节奏稳定。
- 随机数支持种子，确保每日路线可复现。

## 8. 里程碑

1. MVP（2 天）：登记判定、计时、结算。
2. 增强（2 天）：今日林线、本地最佳分、连对加分。
3. 打磨（2 天）：语音引导与护眼模式联动。
4. 扩展（2 天）：主题林区与特殊线索机制（已落地）。

## 9. 验收标准

1. 触屏操作可以稳定巡护一整局。
2. 登记错误反馈明确且可恢复。
3. 结算数据与过程一致。
4. 紧急线索超时与稀有线索奖惩行为符合配置。
5. 主题与天气切换在视觉和提示上可感知。

## 10. 风险与规避

- 风险：线索类型过多导致识别压力增大。
- 规避：低难度限制观察站数量并放慢刷新速度。
