# 05 音乐节奏点击（Rhythm Tap）

## 1. 项目定位

- 类型：节奏反应
- 目标年龄：6-12 岁
- 单局时长：2-4 分钟
- 核心体验：节拍命中、连击反馈、音乐沉浸

## 2. 核心玩法

1. 音符沿轨道下落。
2. 到达判定线时点击对应按键。
3. 判定等级：Perfect / Good / Miss。
4. 曲目结束后按命中率结算评分和星级。

## 3. 主要系统

### 3.1 谱面系统

- 音符数据包含时间戳、轨道、类型。
- 支持长按音符与滑动音符（后续扩展）。

### 3.2 判定系统

- 判定窗可配置：例如 Perfect ±60ms。
- 连击中断时给予温和提示。

### 3.3 曲库系统

- 儿童友好曲目，分简单/普通/困难。
- 每首曲目可配置速度倍率。

### 3.4 成长系统

- 评级解锁新曲与皮肤。
- 每日挑战曲提升留存。

## 4. 页面流程

1. 曲目选择页：难度、最佳成绩。
2. 演奏页：轨道、连击、进度条。
3. 结算页：评分、命中率、奖励。

## 5. 配置结构（示例）

```json
{
  "songId": "KIDS-001",
  "bpm": 120,
  "lanes": 4,
  "judgeWindowMs": {"perfect": 60, "good": 120},
  "notes": [
    {"t": 1.2, "lane": 2, "type": "tap"},
    {"t": 1.8, "lane": 4, "type": "tap"}
  ]
}
```

## 6. 美术与音频

- 轨道简洁高对比，避免视觉噪音。
- 判定文字采用弹性动画。
- 命中音效与背景音乐混音平衡。

## 7. 技术实现要点

- 使用高精度时钟进行音画同步。
- 输入时间戳统一来自同一时基。
- 低端设备提供简化特效模式。

## 8. 里程碑

1. MVP（4 天）：单曲、点击判定、结算。
2. 增强（3 天）：曲库、难度、评级系统。
3. 打磨（2 天）：混音、特效、偏移校准。

## 9. 验收标准

1. 音画偏差稳定可控（体感不漂移）。
2. 同一曲目多次判定结果一致。
3. 低端机可稳定运行简化模式。

## 10. 风险与规避

- 风险：设备差异导致延迟体验差。
- 规避：提供手动延迟校准。
