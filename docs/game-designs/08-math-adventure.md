# 08 算术闯关（Math Adventure）

## 1. 项目定位

- 类型：教育闯关
- 目标年龄：6-11 岁
- 单局时长：3-6 分钟
- 核心体验：做题有目标，答对有战斗反馈

## 2. 核心玩法

1. 出现算术题（加减乘除按年级分层）。
2. 玩家选择正确答案攻击怪物。
3. 连续答对触发技能。
4. 清空敌人通关，错误过多则失败。

## 3. 主要系统

### 3.1 出题系统

- 难度维度：数值范围、运算类型、混合题比例。
- 避免重复题与过于机械的序列。

### 3.2 战斗映射

- 正确答案 = 造成伤害。
- 错误答案 = 玩家扣血或敌人增益。

### 3.3 技能系统

- 连击技能：范围伤害、护盾、加时。
- 技能触发阈值可配置。

### 3.4 学习报告

- 统计错误题型和正确率。
- 自动推荐复习关。

## 4. 页面流程

1. 关卡页：选择章节与难度。
2. 战斗页：题目、选项、战斗表现。
3. 结算页：战绩、错题、奖励。

## 6. 美术与音频

- 轻冒险卡通战斗风。
- 题目区视觉稳定，避免干扰阅读。
- 正确/错误反馈音清晰区分。

## 7. 技术实现要点

- 题目生成器需校验答案唯一性。
- 计时器与战斗动画解耦，避免阻塞。
- 记录错题原始数据便于复盘。

## 8. 里程碑

1. MVP（4 天）：出题、判定、战斗、结算。
2. 增强（3 天）：技能、章节、错题本。
3. 打磨（2 天）：难度平衡、题库扩充。

## 9. 验收标准

1. 题目分布符合目标年级。
2. 同级别连续 3 局难度波动合理。
3. 错题追踪准确可复习。

## 10. 风险与规避

- 风险：题目难度跳跃。
- 规避：用分层题池和动态难度调节。
