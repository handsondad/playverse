# 15 小小邮差送信（Postman Delivery）

## 1. 项目定位

- 类型：颜色匹配 / 反应训练
- 目标年龄：4-9 岁
- 单局时长：3-5 分钟
- 核心体验：识别信件颜色并快速投递到正确信箱

## 2. 核心玩法

1. 系统持续生成待投递信件。
2. 每封信对应一个目标颜色信箱。
3. 玩家点击同色信箱完成投递。
4. 投递正确加分并增加连对，投错扣生命。
5. 在时间结束前达到目标投递数量即可通关。

## 3. 主要系统

### 3.1 难度系统

- 三档难度：社区慢送 / 街区速递 / 城市急送。
- 难度通过刷新间隔、目标数量、可用颜色和生命值体现。

### 3.2 路线系统

- 当前信件显示目标信箱。
- 后续队列展示 5 封待送信件，支持提前规划。
- 今日路线通过日期种子固定，便于重复挑战。

### 3.3 特殊信件系统

- 加急件：必须优先处理，超时会扣生命。
- 挂号件：投递成功奖励更高，投错惩罚更重。
- 队列与当前信件区显示特殊标签，辅助快速判断。

### 3.4 主题与天气系统

- 提供经典邮局 / 校园邮局 / 节日邮局三套主题包。
- 主题切换会同步品牌色、面板底色与每日路线种子。
- 每局按周期轮换天气（晴天、多云、小雨、微风、晚霞等），并同步背景氛围。

### 3.5 评分与反馈

- 投递成功按连对获得额外分数。
- 投递失败给出明确提示并扣减生命。
- 结算展示投递数、分数、生命和剩余时间。

### 3.6 辅助与设置

- 全局语音、播报、护眼模式同步可用。
- 安静模式关闭提示音，减少听觉刺激。

## 4. 页面流程

1. 选择难度。
2. 开始送信或今日路线。
3. 观察当前信件并点击目标信箱。
4. 持续投递直至通关或失败。
5. 查看结算并可快速重开。

## 6. 美术与音频

- 邮局风格配色，信箱按钮使用高对比色块。
- 信件与信箱均采用 emoji 提升低龄识别效率。
- 不同信箱按钮对应不同音高提示。

## 7. 技术实现要点

- 统一 100ms tick 管理时间与信件刷新。
- 队列固定长度，保证节奏稳定。
- 随机数支持种子，确保每日路线可复现。

## 8. 里程碑

1. MVP（2 天）：投递判定、计时、结算。
2. 增强（2 天）：每日路线、本地最佳分、连对加分。
3. 打磨（2 天）：加急件、挂号件与特殊提示。
4. 扩展（2 天）：主题包与天气事件。
5. 进阶（后续）：章节任务。

## 9. 验收标准

1. 触屏操作可以稳定投递一整局。
2. 投递错误反馈明确且可恢复。
3. 结算数据与过程一致。

## 10. 风险与规避

- 风险：颜色过多导致识别压力增大。
- 规避：低难度限制颜色数量并放慢刷新速度。
