# 09 迷宫解谜（Maze Puzzle）

## 1. 项目定位

- 类型：逻辑解谜
- 目标年龄：6-12 岁
- 单局时长：2-6 分钟
- 核心体验：探索路径、机关解锁、解题成就

## 2. 核心玩法

1. 玩家控制角色在迷宫中移动。
2. 收集钥匙、触发机关、避开陷阱。
3. 到达终点即通关。
4. 可选挑战：最短步数、限时完成。

## 3. 主要系统

### 3.1 迷宫生成

- 支持预制关与随机关。
- 随机关需保证可达与复杂度可控。

### 3.2 机关系统

- 地板开关、门锁、传送点、一次性桥。
- 机关状态需可视化反馈。

### 3.3 提示系统

- 失败次数过多时给方向提示。
- 可消耗道具显示推荐路径。

### 3.4 评分系统

- 维度：时间、步数、收集完成度。
- 星级与奖励绑定。

## 4. 页面流程

1. 选关页：章节、最佳记录。
2. 解谜页：迷宫地图、道具、计时。
3. 结算页：成绩、路线回放、下一关。

## 6. 美术与音频

- 方格地形风格，元素辨识清晰。
- 机关触发动画短促明确。
- 氛围音弱化，提示音强化。

## 7. 技术实现要点

- 路径搜索用于可达校验与提示。
- 迷宫状态快照用于撤销或回放。
- 键盘与触控双输入适配。

## 8. 里程碑

1. MVP（4 天）：移动、终点判定、结算。
2. 增强（3 天）：钥匙门、陷阱、评分。
3. 打磨（2 天）：随机迷宫与提示系统。

## 9. 验收标准

1. 每个关卡均可在合理时间内通关。
2. 随机迷宫可达率 100%。
3. 输入操作流畅，无卡格误判。

## 10. 风险与规避

- 风险：难度不可控。
- 规避：通过步骤预算和分层机关模板控难。
