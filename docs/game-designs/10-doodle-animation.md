# 10 涂鸦互动动画（Doodle Animation）

## 1. 项目定位

- 类型：创意表达
- 目标年龄：4-12 岁
- 单局时长：开放时长（3-15 分钟）
- 核心体验：画完就动、创作即反馈

## 2. 核心玩法

1. 孩子在画布上绘制角色或物体。
2. 选择动作模板（跳跃、摆手、旋转）。
3. 一键播放动画。
4. 可录音作为角色配音并导出分享图卡。

## 3. 主要系统

### 3.1 绘制系统

- 画笔、橡皮、颜色盘、图层简化版。
- 自动平滑线条并限制最小笔触。

### 3.2 动画系统

- 骨架模板绑定（简化关键点）。
- 支持循环动作与过渡。

### 3.3 录音系统

- 录制 3-10 秒语音。
- 播放时与角色动画同步触发。

### 3.4 作品系统

- 本地保存作品缩略图和配置。
- 一键生成分享海报或短动图。

## 4. 页面流程

1. 创作页：绘制与编辑工具。
2. 动作页：模板选择与预览。
3. 播放页：播放、录音、导出。
4. 作品库：管理历史作品。

## 5. 配置结构（示例）

```json
{
  "templateId": "jump-basic",
  "anchors": ["head", "leftHand", "rightHand", "body"],
  "durationMs": 1200,
  "loop": true,
  "bgm": "fun-01"
}
```

## 6. 美术与音频

- UI 风格偏画板，工具图标大而直观。
- 动画预览强调“立即响应”。
- 配乐轻松，避免压过录音人声。

## 7. 技术实现要点

- Canvas 绘制结果转纹理后驱动动画。
- 关键点绑定需要容错（缺失点回退默认位）。
- 导出流程分离主线程，避免界面卡顿。

## 8. 里程碑

1. MVP（5 天）：绘制、动作模板、播放。
2. 增强（4 天）：录音、作品库、导出图卡。
3. 打磨（3 天）：更多动作模板与性能优化。

## 9. 验收标准

1. 绘制到播放转换耗时低于 1 秒（常规设备）。
2. 作品保存与再次编辑稳定。
3. 录音与动画可同步播放。

## 10. 风险与规避

- 风险：动画绑定复杂导致体验不稳定。
- 规避：先限制模板和锚点数量，逐步扩展能力。
