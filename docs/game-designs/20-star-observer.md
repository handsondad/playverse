# 20 星空观测员（Star Observer）

## 1. 项目定位

- 类型：类型匹配 / 反应训练
- 目标年龄：4-9 岁
- 单局时长：3-5 分钟
- 核心体验：识别星图线索并快速送到对应观测台

## 2. 核心玩法

1. 系统持续生成待记录的星图线索。
2. 每条线索对应一个目标观测台。
3. 玩家点击同类型观测台完成记录。
4. 记录正确加分并增加连对，记录错误扣精力。
5. 在时间结束前达到目标记录数量即可通关。

## 3. 主要系统

### 3.1 难度系统

- 三档难度：黄昏观星 / 夜空记录 / 银河巡测。
- 难度通过刷新间隔、目标数量、可用观测台和精力值体现。

### 3.2 队列预览系统

- 当前星图显示目标观测台。
- 后续队列展示 5 条线索，支持提前规划。
- 今日星图通过日期种子固定，便于重复挑战。

### 3.3 评分与反馈

- 记录成功按连对获得额外分数。
- 每完成 6 次正确记录奖励 1 秒。
- 记录失败给出明确提示并扣减精力。
- 结算展示记录数、分数、精力和剩余时间。

### 3.4 特殊天象系统（P2）

- 限时信号：出现后需在限时内完成，超时会扣精力。
- 稀有天象：记录正确双倍分，记录错误额外扣精力。
- 队列预览会标记限时/稀有，方便提前决策。

### 3.5 主题星域与天空系统（P2）

- 提供深空观测、月湾夜航、星云秘境三套主题。
- 每个主题绑定独立天空池，局内按周期切换天空状态。
- 天空变化同步在界面与提示文案中展示，增强节奏感。

### 3.6 辅助与设置

- 全局语音、播报、护眼模式同步可用。
- 安静模式关闭提示音，减少听觉刺激。

## 4. 页面流程

1. 选择难度。
2. 选择主题星域并确认当日天空序列。
3. 开始观测或今日星图。
4. 观察当前线索并点击目标观测台。
5. 限时信号优先处理，稀有天象争取高分。
6. 持续记录直至通关或失败。
7. 查看结算并可快速重开。

## 6. 美术与音频

- 夜空与星云配色，观测台按钮采用高对比色块。
- 星图与观测台使用 emoji，提升低龄识别效率。
- 不同观测台按钮对应不同音高提示。

## 7. 技术实现要点

- 统一 100ms tick 管理时间与线索刷新。
- 队列固定长度，保证节奏稳定。
- 随机数支持种子，确保每日星图可复现。

## 8. 里程碑

1. MVP（2 天）：记录判定、计时、结算。
2. 增强（2 天）：今日星图、本地最佳分、连对加分。
3. 打磨（2 天）：语音引导与护眼模式联动。
4. 扩展（2 天）：主题星域与特殊天象机制（已落地）。

## 9. 验收标准

1. 触屏操作可以稳定观测一整局。
2. 记录错误反馈明确且可恢复。
3. 结算数据与过程一致。
4. 限时信号超时与稀有天象奖惩行为符合配置。
5. 主题与天空切换在视觉和提示上可感知。

## 10. 风险与规避

- 风险：符号类型过多导致识别压力增大。
- 规避：低难度限制观测台数量并放慢刷新速度。
