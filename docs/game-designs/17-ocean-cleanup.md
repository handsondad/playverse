# 17 海底清洁队（Ocean Cleanup）

## 1. 项目定位

- 类型：类型匹配 / 反应训练
- 目标年龄：4-9 岁
- 单局时长：3-5 分钟
- 核心体验：识别海面漂浮物并快速放入对应回收网

## 2. 核心玩法

1. 系统持续生成待清理的漂浮物。
2. 每个漂浮物对应一个目标回收网。
3. 玩家点击同类型回收网完成清理。
4. 清理正确加分并增加连对，清理错误扣生命。
5. 在时间结束前达到目标清理数量即可通关。

## 3. 主要系统

### 3.1 难度系统

- 三档难度：海湾巡查 / 礁区守护 / 深海突击。
- 难度通过刷新间隔、目标数量、可用回收网和生命值体现。

### 3.2 队列预览系统

- 当前漂浮物显示目标回收网。
- 后续队列展示 5 个漂浮物，支持提前规划。
- 今日海域通过日期种子固定，便于重复挑战。

### 3.3 特殊漂浮物与主题系统

- 危险品需要优先清理，放置过久会扩散并损失生命。
- 宝藏件清理正确时分数翻倍，分错惩罚更重。
- 提供晴蓝海湾 / 珊瑚礁区 / 夜潮海域三套主题包。
- 每局按周期轮换海况，并同步切换背景氛围。

### 3.4 评分与反馈

- 清理成功按连对获得额外分数。
- 每完成 6 次正确清理奖励 1 秒。
- 清理失败给出明确提示并扣减生命。
- 结算展示清理数、分数、生命和剩余时间。

### 3.5 辅助与设置

- 全局语音、播报、护眼模式同步可用。
- 安静模式关闭提示音，减少听觉刺激。

## 4. 页面流程

1. 选择难度。
2. 开始清理或今日海域。
3. 观察当前漂浮物并点击目标回收网。
4. 持续清理直至通关或失败。
5. 查看结算并可快速重开。

## 6. 美术与音频

- 海洋清爽配色，回收网按钮使用高对比色块。
- 漂浮物与回收网使用 emoji，提升低龄识别效率。
- 不同回收网按钮对应不同音高提示。

## 7. 技术实现要点

- 统一 100ms tick 管理时间与漂浮物刷新。
- 队列固定长度，保证节奏稳定。
- 随机数支持种子，确保每日路线可复现。

## 8. 里程碑

1. MVP（2 天）：分类判定、计时、结算。
2. 增强（2 天）：今日海域、本地最佳分、连对加分。
3. 打磨（2 天）：语音引导与护眼模式联动。
4. 扩展（2 天）：主题海域、特殊漂浮物与天气轮换。

## 9. 验收标准

1. 触屏操作可以稳定清理一整局。
2. 清理错误反馈明确且可恢复。
3. 结算数据与过程一致。

## 10. 风险与规避

- 风险：类型过多导致识别压力增大。
- 规避：低难度限制回收网数量并放慢刷新速度。
