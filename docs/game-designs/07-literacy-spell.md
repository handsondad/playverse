# 07 字母/拼音启蒙（Literacy Spell）

## 1. 项目定位

- 类型：教育启蒙
- 目标年龄：5-9 岁
- 单局时长：2-5 分钟
- 核心体验：拼读练习 + 游戏化反馈

## 2. 核心玩法

1. 给出图片与发音提示。
2. 玩家拖拽字母或拼音片段组成正确答案。
3. 正确后播放完整读音并奖励。
4. 连续通关解锁新词包。

## 3. 主要系统

### 3.1 题库系统

- 按主题组织：动物、食物、日常用品。
- 支持中英文双模式（可选）。

### 3.2 判定系统

- 精确匹配：顺序与字符完全正确。
- 宽容机制：提供 1-2 次提示机会。

### 3.3 发音系统

- 单字点击可听发音。
- 完整答案提交后播报整词。

### 3.4 奖励系统

- 每日学习进度条。
- 连续学习天数奖励徽章。

## 4. 页面流程

1. 选包页：主题与难度。
2. 练习页：图片、字母池、拼接区。
3. 结算页：正确率、发音复习、奖励。

## 5. 配置结构（示例）

```json
{
  "questionId": "A-001",
  "mode": "alphabet",
  "image": "cat.png",
  "answer": ["c", "a", "t"],
  "phonics": ["/k/", "/ae/", "/t/"]
}
```

## 6. 美术与音频

- 图片优先真实可识别物体。
- 字母块需大尺寸、强对比。
- 语音清晰、语速偏慢。

## 7. 技术实现要点

- 拖拽槽位自动吸附与重排。
- 音频播放队列，避免重叠噪音。
- 题库配置支持多语言字段。

## 8. 里程碑

1. MVP（4 天）：题目展示、拼写判定、结算。
2. 增强（3 天）：发音系统、主题包。
3. 打磨（2 天）：学习报告与复习机制。

## 9. 验收标准

1. 孩子可独立完成基础词包。
2. 发音与文本同步准确。
3. 新增词包仅需配置数据与素材。

## 10. 风险与规避

- 风险：教育性与趣味性失衡。
- 规避：控制每题时长，增加即时奖励反馈。
