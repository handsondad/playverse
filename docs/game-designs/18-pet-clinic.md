# 18 小小宠物诊所（Pet Clinic）

## 1. 项目定位

- 类型：类型匹配 / 反应训练
- 目标年龄：4-9 岁
- 单局时长：3-5 分钟
- 核心体验：识别宠物症状并快速安排到对应诊室

## 2. 核心玩法

1. 系统持续生成待接诊病例。
2. 每个病例对应一个目标诊室。
3. 玩家点击同症状诊室完成分诊。
4. 分诊正确加分并增加连对，分诊错误扣耐心。
5. 在时间结束前达到目标接诊数量即可通关。

## 3. 主要系统

### 3.1 难度系统

- 三档难度：晨间接诊 / 午后门诊 / 夜间急诊。
- 难度通过刷新间隔、目标数量、可用诊室和耐心值体现。

### 3.2 队列预览系统

- 当前病例显示目标诊室。
- 后续队列展示 5 个病例，支持提前规划。
- 今日门诊通过日期种子固定，便于重复挑战。

### 3.3 特殊病例与主题系统

- 急诊需要优先分诊，等待过久会降低耐心。
- VIP 分诊正确时分数翻倍，分错惩罚更重。
- 提供暖心诊所 / 花园诊所 / 夜班诊所三套主题包。
- 每局按周期轮换天气，并同步切换背景氛围。

### 3.4 评分与反馈

- 分诊成功按连对获得额外分数。
- 每完成 6 次正确分诊奖励 1 秒。
- 分诊失败给出明确提示并扣减耐心。
- 结算展示接诊数、分数、耐心和剩余时间。

### 3.5 辅助与设置

- 全局语音、播报、护眼模式同步可用。
- 安静模式关闭提示音，减少听觉刺激。

## 4. 页面流程

1. 选择难度。
2. 开始接诊或今日门诊。
3. 观察当前病例并点击目标诊室。
4. 持续分诊直至通关或失败。
5. 查看结算并可快速重开。

## 6. 美术与音频

- 诊所暖色系配色，诊室按钮使用高对比色块。
- 症状与诊室使用 emoji，提升低龄识别效率。
- 不同诊室按钮对应不同音高提示。

## 7. 技术实现要点

- 统一 100ms tick 管理时间与病例刷新。
- 队列固定长度，保证节奏稳定。
- 随机数支持种子，确保每日路线可复现。

## 8. 里程碑

1. MVP（2 天）：分诊判定、计时、结算。
2. 增强（2 天）：今日门诊、本地最佳分、连对加分。
3. 打磨（2 天）：语音引导与护眼模式联动。
4. 扩展（2 天）：主题诊所、特殊病例与天气轮换。

## 9. 验收标准

1. 触屏操作可以稳定分诊一整局。
2. 分诊错误反馈明确且可恢复。
3. 结算数据与过程一致。

## 10. 风险与规避

- 风险：症状类型过多导致识别压力增大。
- 规避：低难度限制诊室数量并放慢刷新速度。
