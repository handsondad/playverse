# 13 动物合唱团（Animal Choir）

## 1. 项目定位

- 类型：记忆节奏 / 听觉训练
- 目标年龄：4-10 岁
- 单局时长：3-6 分钟
- 核心体验：先听后唱，按顺序复现动物合唱

## 2. 核心玩法

1. 系统播放一段动物叫声顺序（例如：猫 -> 鸭 -> 狗）。
2. 玩家按相同顺序点击动物卡片进行“跟唱”。
3. 每轮正确后序列加长 1 个音符，进入下一轮。
4. 在倒计时结束前完成目标轮次即过关。

## 3. 主要系统

### 3.1 关卡系统

- 三档难度：慢慢唱 / 刚刚好 / 合唱大师。
- 难度差异体现在目标轮次、时间限制、可用动物数量。

### 3.2 序列系统

- 每轮在上一轮序列末尾追加一个动物。
- 每日挑战使用日期种子，保证同日序列一致。

### 3.3 提示与容错

- 可使用“提示一个”，告知当前应点击的动物。
- 使用提示会扣除时间，避免无限提示。
- 点错后重置本轮输入并扣除少量时间。

### 3.4 反馈与成长

- 正确输入有即时音效反馈。
- 记录本地“最好连对”。
- 结算展示轮次、连对、提示次数和剩余时间。

### 3.5 模仿与完美奖励

- 展示“模仿轨迹”条，播放阶段与输入阶段都会显示当前步骤。
- 单轮无失误且未用提示判定为完美回合，触发加时奖励。
- 连续完美会提升奖励，并记录最佳完美连击。

## 4. 页面流程

1. 选择难度。
2. 点击开始演奏（或今日合唱）。
3. 听系统播放序列。
4. 跟唱输入。
5. 通关或时间结束后结算。

## 5. 配置结构（示例）

```json
{
  "id": "normal",
  "name": "刚刚好",
  "targetRounds": 7,
  "timeLimitSec": 80,
  "animalIds": ["cat", "dog", "duck", "frog", "cow"]
}
```

## 6. 美术与音频

- 动物卡片使用高对比底色 + emoji，提升识别速度。
- 当前播放/当前激活动物增加高亮缩放反馈。
- 每种动物对应不同音高，形成可记忆旋律。

## 7. 技术实现要点

- 随机数支持可注入种子，便于每日挑战复现。
- 游戏状态机至少包含：idle / watch / input / done。
- 听序列与输序列阶段要严格分离，避免误触输入。

## 8. 里程碑

1. MVP（2-3 天）：基础序列、输入判定、结算。
2. 增强（2 天）：每日挑战、提示、本地最好连对。
3. 打磨（2 天）：主题音色包、模仿轨迹、连续完美奖励。
4. 扩展（2 天）：奖励贴纸与章节任务。

## 9. 验收标准

1. 4-6 岁儿童可在指引下完成一局。
2. 听序列阶段按钮不可误输入。
3. 错误与提示反馈明确，不会让玩家卡死。

## 10. 风险与规避

- 风险：听觉记忆门槛过高导致挫败。
- 规避：低难度减少动物种类，并提供扣时提示机制。
