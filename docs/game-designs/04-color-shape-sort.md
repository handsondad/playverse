# 04 颜色/形状分类（Color & Shape Sort）

## 1. 项目定位

- 类型：启蒙认知
- 目标年龄：3-7 岁
- 单局时长：1-2 分钟
- 核心体验：拖拽操作直观、反馈友好

## 2. 核心玩法

1. 屏幕出现多个物体（颜色与形状不同）。
2. 玩家拖拽物体到对应分类盒。
3. 分类正确得分，错误返回原位并提示。
4. 在时间内完成全部分类即通关。

## 3. 主要系统

### 3.1 题目生成

- 维度：颜色、形状、尺寸（可逐步开启）。
- 干扰项：同色异形、同形异色。

### 3.2 引导系统

- 语音提示：例如“把红色圆形放到这里”。
- 高亮提示：首次错误时高亮正确目标。

### 3.3 奖励系统

- 连续正确触发小奖励动画。
- 关卡完成发放贴纸。

## 4. 页面流程

1. 首页：开始、模式选择（颜色/形状/混合）。
2. 游戏页：拖拽区、分类盒、计时。
3. 结算页：准确率、奖励贴纸、下一关。

## 5. 配置结构（示例）

```json
{
  "levelId": "S1",
  "mode": "color",
  "itemCount": 8,
  "categories": ["red", "blue", "yellow"],
  "timeLimit": 90,
  "enableVoiceHint": true
}
```

## 6. 美术与音频

- 高对比度颜色，避免难区分配色。
- 拖拽吸附动画提升操作成功感。
- 错误提示音轻柔，避免挫败。

## 7. 技术实现要点

- 拖拽判定使用目标区域碰撞盒。
- 移动端优先触摸事件，兼容鼠标。
- 统一手势阈值，减少误触。

## 8. 里程碑

1. MVP（2-3 天）：拖拽分类与结算。
2. 增强（2 天）：语音提示与混合模式。
3. 打磨（1 天）：交互动效与无障碍颜色优化。

## 9. 验收标准

1. 3 岁儿童可在引导下完成首关。
2. 误触率可控，拖拽反馈及时。
3. 配置可快速新增 20+ 题目。

## 10. 风险与规避

- 风险：关卡变化不足。
- 规避：增加目标规则组合与主题包。
