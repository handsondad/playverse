# 02 翻牌配对（Memory Match）

## 1. 项目定位

- 类型：记忆益智
- 目标年龄：4-9 岁
- 单局时长：1-3 分钟
- 核心体验：观察、记忆、稳定成就感

## 2. 核心玩法

1. 所有卡牌背面朝上。
2. 每次可翻两张，图案相同则消除。
3. 不同则短暂展示后翻回。
4. 清空棋盘即通关。

## 3. 主要系统

### 3.1 棋盘系统

- 尺寸：3x4、4x4、4x5。
- 洗牌：使用可复现随机种子，便于调试。

### 3.2 计分与星级

- 基础分：每对 +20。
- 时间加分：剩余时间越多分越高。
- 失误扣分：重复错误匹配扣分。
- 星级：根据用时/失误/连击综合评定。

### 3.3 道具系统

- 提示：高亮一对可匹配卡。
- 全览：1 秒展示全部正面。
- 保险：一次错误不计惩罚。

### 3.4 主题系统

- 主题包：动物、交通、字母、节日。
- 同一套逻辑切换资源即可扩展。

## 4. 页面流程

1. 首页：开始、难度、主题、历史最佳。
2. 游戏页：网格卡牌、计时、步数、道具。
3. 结算页：星级、奖励、下一关。

## 6. 美术与音频

- 卡牌正反面统一尺寸与留白。
- 翻牌动画 180 度旋转。
- 匹配成功播放轻快音效，失败用温和提示。

## 7. 技术实现要点

- 状态机：idle -> first-open -> checking -> resolving。
- 阻止重复点击同一张牌导致状态错乱。
- 统一输入锁，判定期间禁止新翻牌。

## 8. 里程碑

1. MVP（3 天）：翻牌、匹配、通关。
2. 增强（2 天）：主题包、道具、星级。
3. 打磨（1 天）：动画、引导、存档。

## 9. 验收标准

1. 不出现卡牌状态错乱。
2. 数据可配置新增关卡，无需改核心逻辑。
3. 儿童可连续游玩 3 局。

## 10. 风险与规避

- 风险：后期重复感强。
- 规避：加入每日挑战、主题轮换、特殊规则关。
